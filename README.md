# fami_war_like

ファミコンウォーズのようなゲームを作ってみたいです

往年のターン制ウォーシミュレーションに着想を得たオリジナル作品「グリッドウォーズ(仮題)」の開発リポジトリです。
TypeScript + Phaser + Vite で開発し、ブラウザで遊べるWebゲームとして公開します。
