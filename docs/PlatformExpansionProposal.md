# 提案: Steam 配信実績の獲得による配信プラットフォームの拡大

| 項目 | 内容 |
|---|---|
| 文書名 | 配信プラットフォーム拡大の提案(簡易版) |
| 対象プロダクト | グリッドウォーズ(仮題) — ブラウザで遊べるターン制ウォーシミュレーション |
| 作成日 | 2026-09-10 |
| 本書の位置づけ | **「なぜこの PJ を商用化するのか」を 1 枚で説明するための資料**。実行計画の詳細は `docs/CommercialProposal.md` を参照 |

## 1. 課題

**社内のゲーム開発実績が Google Play のみに限られている。**

そのため、以下の制約が生じています。

- 提案できる配信先が Google Play(Android)に偏り、**PC 向け配信を含む案件に実績で応えられない**
- Steam の申請・審査・ストア運用・PC 向けビルドといった**実務ノウハウが社内に蓄積されていない**
- 実績がないため、次に PC 配信の話が来ても**やれるかどうかの判断材料がない**

## 2. 提案

**本 PJ「グリッドウォーズ(仮題)」を Steam でリリースし、社内初の Steam 配信実績をつくる。**

このプロジェクトの主目的は、ゲーム単体の売上ではなく、**Steam という配信チャネルを社内の実績と能力として獲得すること**です。

```
  現在                          本 PJ 実施後
  ┌──────────────┐              ┌──────────────────────────┐
  │ Google Play  │      ─→      │ Google Play  +  Steam    │
  │ のみ          │              │ (PC 配信の実績とノウハウ)  │
  └──────────────┘              └──────────────────────────┘
        │                                    │
   提案できる案件が                    後続案件で配信先を
   Android に限られる                  選べる・提案できる
```

## 3. なぜこの PJ が適しているか

| 理由 | 内容 |
|---|---|
| **すでに動くものがある** | 約 1 か月の開発でユニット 22 種・マップ 14 枚・CPU 指揮官 5 人を実装済み。一通り遊べる状態に到達しており、ゼロから作る必要がない |
| **追加費用がほぼかからない** | アート・サウンドを含め全工程を内製する方針のため、実費は数万円〜十数万円(Steam 登録料 100 USD ほか)にとどまる |
| **権利がクリーン** | 画像・音源とも外部素材を一切使っていない(すべてコード生成・合成音)。依存ライブラリも MIT ライセンスの Phaser のみで、権利面のリスクが小さい |
| **ジャンルとの相性** | PC 向けターン制ストラテジーは Steam と相性が良く、実績づくりの題材として現実的 |

## 4. 得られるもの

**主目的 — 社内の能力と実績**

- Steam 配信の実務ノウハウ(申請・審査・ストアページ・レーティング取得・決済・アップデート運用)
- PC 向けビルド(デスクトップアプリ化)の技術的な知見
- 「Steam 配信実績あり」という**後続案件で使える提案材料**

**副次的なもの**

- 製品の売上(1,200 円想定。詳細な試算は `docs/CommercialProposal.md`)
- ブラウザ体験版を残すことによる、リンク 1 つで配れる自社プロダクトの獲得

> 売上は副次的な位置づけです。**実績とノウハウの獲得が主目的**であるため、売上が伸びなくても投資の目的は達成されます。

## 5. 進め方

| 項目 | 内容 |
|---|---|
| 期間 | **最長 9 か月**(9 か月を上限として固定し、遅れた場合は期間を延ばさずスコープを削る) |
| 体制 | 現行の個人体制を継続。外注なし |
| 費用 | 実費で数万円〜十数万円。実質のコストは開発者の時間(6〜8 人月) |
| 進め方 | 5 つの Phase に分け、各段階で続行を判断する。**まず Phase 1(検証・1 か月・追加費用ほぼ無し)のみ承認いただきたい** |

## 6. お願いしたいこと

| # | 内容 |
|---|---|
| 1 | **IP(著作権)の権利帰属の整理** — 会社の事業として進めるのか、個人の資産として扱うのか。着手前に確定が必要 |
| 2 | **Phase 1(検証)の実施可否のご判断** — 1 か月・追加費用はほぼ発生しない |
| 3 | **法務支援の窓口** — 商標調査・利用規約・プライバシーポリシーの整備 |
