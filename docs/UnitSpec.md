# Unit Spec

## 方針

MVPではユニット数を絞り、移動・攻撃・占領・生産の基本ループを検証します。
本格的なバランス調整やユニット追加は、コアループが動作してから行います。

戦闘機・爆撃機・攻撃機・戦闘ヘリ・輸送ヘリは**飛行ユニット**で、空港で生産できる。
対空戦車・対空自走砲・対空ロケット砲は地上ユニットで、工場・本拠地で生産できる。
射程「なし」は攻撃できないユニット(輸送ヘリ・輸送艦)を表す。

固定翼機は**戦闘機・爆撃機・攻撃機の 3 種**に分かれ、狙える相手で役割がはっきり分かれる。
戦闘機は飛行ユニットだけ、爆撃機は地上・海上ユニットだけを攻撃でき、攻撃機はその両方を撃てる
かわりに、それぞれの専門機には及ばない火力になっている。いずれも移動タイプは `air` で、
移動力は戦闘機 10 > 攻撃機 9 > 爆撃機 8、視界はすべて 2。

対空ユニットは**対空戦車・対空自走砲・対空ロケット砲の 3 種**で、射程で役割が分かれる。
対空戦車(射程 1)だけは歩兵・車両も攻撃できる(ただし重戦車は攻撃できない)が、対空自走砲(射程 2〜3)と
対空ロケット砲(射程 3〜5)は**飛行ユニット以外をまったく攻撃できない**間接攻撃ユニットで、
そのかわり反撃を受けない。対空自走砲の移動タイプは自走砲と同じ `vehicle`(装軌)、
対空ロケット砲はロケット砲と同じ `wheeled`(装輪)。
**防御力(受けるダメージ)は、対空自走砲が自走砲と、対空ロケット砲がロケット砲と同じ**。
なお、飛行ユニット以外を撃てないこの 2 種は、**空港が 1 マスもないマップでは生産できない**
(飛行ユニットが出てこないマップでは使い道がないため。歩兵・車両も撃てる対空戦車は制限なし)。
詳細は `docs/GameDesign.md`「マップに空港がない場合の生産制限」を参照。

戦車は**軽・中・重の 3 種**に分かれる。コストが上がるほど装甲と火力が増し、
移動力(6 → 5 → 4)と視界(3 → 2 → 1)が下がる。3 種とも近接攻撃のみ・移動タイプは
`vehicle`(装軌)で、上位の戦車には正面から撃ち勝てない関係になっている。

輸送車は歩兵を 1 体運ぶ**地上の輸送ユニット**で、工場・本拠地で生産できる。移動タイプは
戦車 3 種・自走砲・対空戦車・対空自走砲と同じ `vehicle`(装軌)なので、森を抜けて前線へ歩兵を送り込める。
射程 1 の近接攻撃を持ち、**攻撃相性(与ダメージ・被ダメージとも)は偵察車とまったく同じ**。

偵察車・ロケット砲・対空ロケット砲は**地上ユニット**で工場・本拠地で生産できるが、移動タイプは
装軌車両とは別の `wheeled`(装輪)を持つ。道路・拠点を移動コスト 1 で走り抜ける代わりに、
平地はコスト 2、海岸はコスト 4 と重く、森・山へはまったく進入できない
(詳細は `docs/TerrainSpec.md`「装輪車両(偵察車・ロケット砲・対空ロケット砲)の移動」を参照)。

戦艦・護衛艦・輸送艦・潜水艦は**海上ユニット**で、**港**(`port`)で生産できる。
海上ユニットは海と港の上だけを移動でき、陸地には進入できない
(地形ごとの移動コストは `docs/TerrainSpec.md` を参照)。

## 移動タイプ

地上系(歩兵・装軌車両・装輪車両)に加え、飛行系・海上系を扱います。

| 移動タイプ | 説明 | 持つユニット |
|---|---|---|
| infantry | 歩兵系。山や森に進入しやすい | 歩兵 |
| vehicle | 装軌車両系。道路では移動しやすいが山・海は進入できない | 軽・中・重戦車、自走砲、対空戦車、対空自走砲、輸送車 |
| wheeled | 装輪車両系。道路・拠点は速い(コスト1)が、平地は2・海岸は4と重く、森・山・海には進入できない | 偵察車、ロケット砲、対空ロケット砲 |
| air | 飛行系。すべての地形の上を一定コスト(1)で移動でき、海や山も越えられる | 戦闘機、爆撃機、攻撃機、戦闘ヘリ、輸送ヘリ |
| sea | 海上系。海と港の上だけを移動コスト 1 で進み、陸地には進入できない | 戦艦、護衛艦、輸送艦、潜水艦 |

## 攻撃ルール

### 直接攻撃

射程1の攻撃です。
隣接する敵ユニットを攻撃できます。
歩兵・軽戦車・中戦車・重戦車・戦闘機・爆撃機・攻撃機・戦闘ヘリ・対空戦車・偵察車・輸送車が
直接攻撃を行います。

### 間接攻撃

射程2以上の攻撃です。
隣接した敵には攻撃できません。
自走砲(射程2-3)・ロケット砲(射程3-5)・対空自走砲(射程2-3)・対空ロケット砲(射程3-5)・
戦艦(射程3-6)が間接攻撃を行います。

間接攻撃ユニットは**移動した場合は攻撃できません**。攻撃するにはその場に留まる(移動しない)必要があります。直接攻撃ユニットは移動後も攻撃できます。このルールは自軍・敵AIの双方に適用されます。

### 攻撃できないユニット

輸送ヘリ・輸送艦は攻撃できません(射程 0)。移動と輸送(搭乗・降車)のみを行います。

### 攻撃できない「相手」

射程とは別に、**種別の組み合わせによって攻撃できない相手**があります。
相性表(`BASE_DAMAGE`)の基礎ダメージが 0 の組み合わせは、射程内にいても攻撃対象にならず、
反撃も発生しません。判定は `src/core/battle/AttackRange.ts` の `canAttackUnit` が担います。

| 攻撃側 | 攻撃できない相手 |
|---|---|
| 戦艦 | 潜水艦 |
| 護衛艦 | ヘリ系(戦闘ヘリ・輸送ヘリ)と潜水艦**以外**のすべて |
| 潜水艦 | 海上ユニット**以外**のすべて(地上・飛行には手が出せない) |
| 偵察車・輸送車 | 海上ユニット(戦艦・護衛艦・輸送艦・潜水艦)すべて |
| 対空戦車 | 重戦車(機関砲では正面装甲を抜けない) |
| ロケット砲 | 飛行ユニット(戦闘機・爆撃機・攻撃機・戦闘ヘリ・輸送ヘリ) |
| 戦闘機 | 地上ユニット・海上ユニット**すべて**(飛行ユニットだけを攻撃できる) |
| 爆撃機 | 飛行ユニット**すべて**と潜水艦 |
| 攻撃機 | 潜水艦 |
| 対空自走砲・対空ロケット砲 | 飛行ユニット**以外**のすべて |
| 対空 3 種以外の地上ユニット | 固定翼機(戦闘機・爆撃機・攻撃機) |
| 戦闘ヘリ | 固定翼機(戦闘機・爆撃機・攻撃機) |
| 戦艦以外の海上ユニット | 固定翼機(戦闘機・爆撃機・攻撃機) |
| 輸送ヘリ・輸送艦 | すべて(攻撃できないユニット) |
| 上記以外のユニット | 潜水艦(潜水艦を攻撃できるのは護衛艦と潜水艦だけ) |

### 飛行ユニットへの地形防御

飛行ユニット(戦闘機・爆撃機・攻撃機・戦闘ヘリ・輸送ヘリ)は地形の**上空**にいるものとして扱い、
攻撃を受けても地形の防御補正を受けません(常に防御 0 で計算)。
森や山の上にいても防御は上がらないため、対空ユニットで狙い撃ちできます。

**ヘリ系(戦闘ヘリ・輸送ヘリ)** は MVP の簡易化として、対空戦車以外の地上ユニット
(戦車 3 種・自走砲など)からも攻撃されますが、与ダメージは低く抑えています(相性表を参照)。
**ロケット砲だけはヘリ系もまったく攻撃できません**(相性表が 0)。

**固定翼機(戦闘機・爆撃機・攻撃機)** はヘリ系より高いところを速く飛ぶものとして扱い、
狙える側が大きく限られます(相性表が 0)。

- 地上ユニットでは**対空 3 種(対空戦車・対空自走砲・対空ロケット砲)だけ**が攻撃できる
- 海上ユニットでは**戦艦だけ**が攻撃できる。近接対空の護衛艦でもヘリ系までしか届かない
- 飛行ユニットでは**戦闘機・攻撃機だけ**が攻撃できる。戦闘ヘリの武装では捉えられない

つまり固定翼機に対抗できるのは、**対空 3 種・戦艦・戦闘機・攻撃機の 6 種だけ**です。

対空を担うユニットは射程で役割が分かれます。

| ユニット | 射程 | 対飛行ユニットの基礎ダメージ | 備考 |
|---|---|---:|---|
| 対空戦車 | 1 | 70〜90 | 歩兵・車両も攻撃できる(重戦車は不可)。反撃を受ける |
| 対空自走砲 | 2〜3 | 60〜70 | 安価。飛行ユニット以外は撃てず、反撃を受けない |
| 対空ロケット砲 | 3〜5 | 75〜90 | 長射程。飛行ユニット以外は撃てず、反撃を受けない |
| 護衛艦 | 1 | 75〜80 | 海の近接対空。ヘリ系のみ(固定翼機は撃てない)。潜水艦も撃てる |
| 戦艦 | 3〜6 | ヘリ系 85〜90 / 固定翼機 60〜80 | 固定翼機を撃てる唯一の海上ユニット |

戦艦・対空自走砲・対空ロケット砲は間接攻撃なので、**最小射程の内側に踏み込まれた飛行ユニットは
撃てません**。近寄られた相手を叩くのは射程 1 の対空戦車・護衛艦の役目です。
逆に、間接攻撃の対空ユニットは撃たれる側から反撃されないため、
**対空戦車が前に出て受け、対空自走砲・対空ロケット砲が後ろから撃つ**のが基本の組み立てになります。

## 合流ルール

耐久値(HP)が減った自軍の同じ種別のユニット同士を合流させ、2 体を 1 体にまとめられます。

- 合流できるのは **同じ軍・同じ種別** で、**双方とも HP が減っている**(現在 HP < 最大 HP)組み合わせのみ
- 合流先の HP に合流元の HP を **合算**し、**最大 HP で頭打ち**にする(超過ぶんは切り捨て)
- 合流元は盤面から取り除かれ、合流先は待機(行動済み)になる
- 詳細な操作・UI は `docs/GameDesign.md` の「合流」を参照

## 輸送ルール

輸送ユニットは他のユニットを運べます。運べる数・種別はユニットごとに異なります。

| 輸送ユニット | 運べる数 | 運べる種別 |
|---|---:|---|
| 輸送ヘリ | 1 | 歩兵 |
| 輸送車 | 1 | 歩兵 |
| 輸送艦 | 2 | すべての地上ユニット(歩兵・軽/中/重戦車・自走砲・ロケット砲・対空戦車・対空自走砲・対空ロケット砲・偵察車・輸送車) |

- **搭乗(乗せる)**: 自軍のユニットを、移動範囲内にいる自軍の空きのある輸送ユニットのマスへ
  動かすと搭乗できる。搭乗したユニットは盤面から取り除かれて輸送ユニットに保持され、
  そのユニットのターンは終了(行動済み)する。
  搭乗できるのは **同じ軍・輸送可能な種別・空き枠がある** 場合のみ。
  輸送艦は海上ユニットなので、地上ユニットが乗り込めるのは **港・海岸に停泊しているとき** だけ。
  海岸は歩兵・装軌車両とも移動コスト 2 で進入できるため、港が無い浜辺でも戦車 3 種・自走砲・
  対空戦車・対空自走砲を積み降ろしできる(装輪車両の偵察車・ロケット砲・対空ロケット砲は
  海岸コスト 4 で揚陸に向かない)。
- **降車(降ろす)**: ユニットを乗せた輸送ユニットは、移動後のコマンドメニューに「降ろす」が出る。
  選ぶと降ろせる隣接マス(空きマスかつ降ろすユニットが進入できる地形)が示され、
  選んだマスへ配置する。輸送艦のように 2 体乗せている場合は、降ろす 1 体ごとにボタンが並ぶ。
  降ろしたユニットと輸送ユニットはどちらもそのターンは行動済みになる。
  ただし **2 体乗せている場合は 1 ターンに 2 体とも降ろせる**。1 体降ろすとコマンドメニューへ戻り、
  残りのユニットに降ろせる隣接マスがあれば続けて降ろせる。降ろせる場所が無くなったら
  そこで行動を終える(待機)。1 体でも降ろすとその移動は確定し、取り消せなくなる。
- **輸送中のダメージ**: 輸送ユニットが攻撃を受けると、**輸送中のユニットも同じダメージを受ける**。
  巻き添えで HP が 0 になった搭乗ユニットは失われる。輸送ユニットが撃破された場合は、
  乗せていたユニットもすべて一緒に失われる(盤面には戻らない)。
- 判定ロジックは `src/core/units/transport.ts`(`canCarry`)、状態更新は `UnitManager`
  (`carryUnit` / `dropUnit`)、移動先・降車先の探索は `MovementRange`
  (`findTransportTargets` / `findUnloadPositions`)、ダメージ波及は `BattleManager` が担う。

## 生産拠点と生産可能ユニット

生産拠点(地形)ごとに生産できるユニット種別が分かれます。

| 生産拠点 | 生産できるユニット |
|---|---|
| 工場・本拠地 | 歩兵・偵察車・輸送車・軽戦車・中戦車・重戦車・自走砲・ロケット砲・対空戦車・対空自走砲・対空ロケット砲(地上ユニット) |
| 空港 | 戦闘ヘリ・輸送ヘリ・戦闘機・爆撃機・攻撃機(飛行ユニット) |
| 港 | 輸送艦・護衛艦・潜水艦・戦艦(海上ユニット) |

対応は `src/data/unitData.ts` の `PRODUCIBLE_UNIT_TYPES_BY_TERRAIN` で定義し、
`ProductionManager` が生産時にこの対応で生産可否を判定します。

さらに、マップの構成による制限として、**空港が 1 マスもないマップでは工場・本拠地の一覧から
対空自走砲・対空ロケット砲が外れます**(飛行ユニットしか攻撃できないため)。
この判定は `MapManager.hasAirport` をもとに `ProductionManager.mapContext()` が組み立て、
`producibleUnitTypesAt` / `isProducibleAt` に渡します。盤面に飛行ユニットがいる場合は制限しません。

## 反撃ルール

MVPでは以下の簡易ルールを採用します。

- 直接攻撃を受けた側が射程内に攻撃側を捉えている場合、反撃できる
- 間接攻撃に対しては原則反撃できない
- 反撃時のダメージは、反撃側の残HPに応じて低下する
- 種別として攻撃できない相手には反撃できない(例: 潜水艦に殴られた戦艦は撃ち返せない)

### 反撃は「向き」ごとに決まる

相性表(`BASE_DAMAGE`)は攻撃側 → 防御側の向きごとに値を持つため、
**片側からしか攻撃が通らない組み合わせ**が生まれます。

| 組み合わせ | 基礎ダメージ | 結果 |
|---|---:|---|
| 重戦車 → 対空戦車 | 85 | 一方的に叩ける(対空戦車は撃ち返せない) |
| 対空戦車 → 重戦車 | 0(×) | 攻撃対象にできない(仕掛けること自体ができない) |

対空戦車の機関砲では重戦車の正面装甲を抜けない、という位置づけです。
判定は `src/core/battle/AttackRange.ts` の `canAttackUnit` / `canCounterattack` が担い、
戦闘の実行(`BattleManager`)と予測(`BattleForecast`)の双方が同じ判定を使います。

相性の要点(依頼仕様との対応):

- **軽戦車**: 対歩兵は 6 割(60)。自走砲・対空戦車には 6 割で有利だが、
  中戦車(40 対 60)・重戦車(25 対 80)には正面から撃ち勝てない。
  ヘリ系は 1〜2 割で、特に戦闘ヘリには不利(10 対 65)。水上艦には 1 割、潜水艦は攻撃できない。
- **中戦車**: 対歩兵は 7〜8 割(75)。軽戦車には 6 割で有利、重戦車には不利(40 対 65)。
  自走砲・対空戦車には 7〜8 割。ヘリ系は 1〜2 割で、戦闘ヘリとは五分五分(15 対 55)。
  水上艦には 1〜2 割、潜水艦は攻撃できない。
- **重戦車**: 対歩兵は 8〜9 割(85)。軽戦車に 8 割・中戦車に 6〜7 割で、戦車 3 種では最強。
  自走砲には 8 割、対空戦車には 8〜9 割。**対空戦車の側は重戦車を攻撃できない(0)**ため、
  仕掛けられることも反撃されることもなく一方的に叩ける(「反撃ルール」参照)。
  同じく軽装甲の**偵察車・輸送車からも 5 しか受けない**(軽戦車 20・中戦車 15 よりさらに硬い)。
  ヘリ系は 1〜2 割だが、戦闘ヘリには若干有利(20 対 45)。
  水上艦には 2 割、潜水艦は攻撃できない。
- **ロケット砲**: 射程 3〜5 の間接攻撃のみ。対歩兵は 8〜9 割(85)で、戦車は装甲が厚くなるほど
  通りにくい(軽80・中65・重45)。自走砲は 6〜7 割、対空戦車は 8 割。
  戦艦には 3〜4 割、護衛艦・輸送艦には 6 割で、潜水艦は攻撃できない。
  **飛行ユニットにはまったく攻撃できない(0)**。
  そして**地上ユニットの中でもっとも防御力が低い**: どの攻撃側から見ても、
  ロケット砲への与ダメージが地上ユニット中で最大になるよう表を組んでいる
  (同じ防御力を持つ対空ロケット砲だけは並ぶ)。
- **戦闘機**: 飛行ユニットだけを攻撃する制空ユニット。戦闘ヘリ 90・輸送ヘリ 95(9〜10割)、
  爆撃機 85(8〜9割)、攻撃機 70(7割)で、**飛行ユニットの中では対空戦最強**。
  地上ユニット・海上ユニットにはまったく攻撃できない(0)。同じ戦闘機同士は 55 で五分。
  撃ち落とせるのは対空 3 種・戦艦・攻撃機だけなので、制空権を取ると落としにくい。
- **爆撃機**: 地上ユニット全てに 80〜90(8〜9割)。戦艦には 45(4〜5割)、護衛艦・輸送艦には 70(7割)。
  **飛行ユニットにはまったく攻撃できない(0)** ため、戦闘機・攻撃機に襲われても撃ち返せない。
  潜水艦も攻撃できない。
- **攻撃機**: 戦闘機と爆撃機の中間。歩兵・偵察車・輸送車・自走砲・対空自走砲は 70(7割)、
  戦車は軽 85・中 75・重 55、ロケット砲・対空ロケット砲は 90。
  海上ユニットに強く、戦艦 65(6〜7割)・護衛艦・輸送艦 90(9割)。潜水艦は攻撃できない。
  空戦では戦闘機に不利(35)だが、爆撃機 75・ヘリ系 85〜90 は狩れる。
- **戦闘ヘリ**: 対歩兵に強い(80 ≒ 8割有利)、戦車は軽65・中55・重45 と重いほど分が悪い、
  自走砲には中程度(50 ≒ 4〜6割)、対空戦車には不利(15)。
  **固定翼機(戦闘機・爆撃機・攻撃機)には攻撃できない(0)**。
- **輸送ヘリ・輸送艦**: 攻撃できないため全対象 0。
- **対空戦車**: 飛行ユニット・歩兵に強い(戦闘ヘリ85・輸送ヘリ90・歩兵80 ≒ 8〜9割有利)。
  固定翼機にも戦闘機70・爆撃機85・攻撃機80 と高い火力を持つ射程 1 の対空ユニット。
  戦車には不利(軽20・中15 ≒ 1〜2割)で、**重戦車にはまったく攻撃できない(0)**。
  重戦車に殴られても反撃できないため、重戦車の相手は戦車・自走砲に任せる。
- **対空自走砲**: 射程 2〜3 で飛行ユニット全てに 60〜70(6〜7割)。
  **飛行ユニット以外はまったく攻撃できない(0)**。防御力(被ダメージの列)は自走砲と同じ。
- **対空ロケット砲**: 射程 3〜5 で戦闘機に 75(7〜8割)、それ以外の飛行ユニットには 85〜90(8〜9割)。
  **飛行ユニット以外はまったく攻撃できない(0)**。防御力(被ダメージの列)はロケット砲と同じで、
  ロケット砲と並んで地上ユニット中もっとも打たれ弱い。
- 対空戦車以外の地上ユニット(戦車 3 種・自走砲)はヘリ系への攻撃力が低い(10〜20)。
  ロケット砲にいたってはヘリ系も攻撃できない(0)。
  **固定翼機(戦闘機・爆撃機・攻撃機)を攻撃できる地上ユニットは対空 3 種だけ**で、
  それ以外の地上ユニットはすべて 0。
- **偵察車**: 近接攻撃のみ。対歩兵は 6〜7 割(65)だが、戦車系(軽20・中15・**重5**・自走砲20・
  対空戦車15)とヘリ系(戦闘ヘリ10・輸送ヘリ20)には不利で、**海上ユニットには攻撃できない(0)**。
  装甲が薄く、中戦車(80)・戦艦(80)・戦闘ヘリ(75)からは大きなダメージを受ける。
  戦って勝つユニットではなく、移動力 8 と視界 5 を活かして索敵・拠点への先回りに使う。
  なお装甲の薄いロケット砲だけは、偵察車の機関銃でも 7 割を削れる。
- **輸送車**: 近接攻撃のみ。**攻撃側の行・防御側の列とも偵察車とまったく同じ値**にそろえている
  (重戦車への 5 も同じ)。
  歩兵を運ぶことが役目で、戦って勝つユニットではない(自衛用の機関銃しか積んでいない)。
- **戦艦**: 対歩兵は 6 割、対戦車系(戦車 3 種・自走砲・対空戦車)は 7〜8 割、
  ヘリ系には 8〜9 割、対輸送艦・護衛艦は 9 割。潜水艦にだけは攻撃できない(0)。
  **固定翼機を撃てる唯一の海上ユニット**で、速い機体ほど捉えにくい
  (戦闘機 60・攻撃機 70・爆撃機 80)。
- **護衛艦**: ヘリ系(7〜8割)と潜水艦(9割)のみ攻撃できる。それ以外の相手はすべて 0。
  **固定翼機も撃てない**ため、爆撃機・攻撃機に殴られても撃ち返せない。
  対空火力そのものは戦艦のほうが上だが、戦艦は射程 3〜6 の間接攻撃なので**隣接した飛行ユニットは撃てない**。
  近寄られた飛行ユニットを叩けるのは射程 1 の護衛艦で、両者は射程で役割が分かれる。
- **潜水艦**: 海上ユニットのみ攻撃でき、戦艦に 9 割・輸送艦に 8〜9 割。
  対潜装備を持つ護衛艦にだけは 2〜3 割しか通らない。
- 潜水艦を攻撃できるのは**護衛艦と潜水艦だけ**。それ以外のユニットは 0(発見・攻撃できない)。

数値は基礎ダメージの仮値です。実装後にプレイ感を見ながら調整します。

## 夜戦

夜戦(マップ選択画面で選ぶ戦闘モード)では、自軍の視界の外が暗くなり敵ユニットが見えなくなります。
ゲームルールとしての詳細は `docs/GameDesign.md`「夜戦」を参照してください。ここではユニット側の
パラメータだけをまとめます。

- `vision`: そのユニットの周囲何マスまでを明るくする(敵を発見できる)か。
- `mountainVisionBonus`: 山の上にいるときの視界の加算値。**歩兵のみ 3**(山では視界 5)。
- `nightStealth`: **潜水艦のみ true**。夜戦では、視界に入っていても**隣接するまで発見できない**。

|---|---:|---|

| 軽戦車 | 3 | 戦車 3 種でもっとも広い。前に出て索敵しやすい |
| 中戦車 | 2 | |
| 重戦車 | 1 | 戦車 3 種でもっとも狭い。単独で突出すると不意打ちを受けやすい |
| 自走砲 | 1 | 射程(2〜3)より視界が狭く、単独では撃てる相手を見つけられない |
| ロケット砲 | 1 | 射程(3〜5)に対して視界が極端に狭い。索敵役なしでは最大射程を使えない |
| 対空戦車 | 2 | |
| 対空自走砲 | 1 | 射程(2〜3)より視界が狭い。自走砲と同じ |
| 対空ロケット砲 | 1 | 射程(3〜5)に対して視界が極端に狭い。ロケット砲と同じ |
| 戦闘機 | 2 | 移動力 10 で飛び回るが、地上の細かい様子は見えない |
| 爆撃機 | 2 | |
| 攻撃機 | 2 | |
| 輸送ヘリ | 2 | |
| 戦闘ヘリ | 3 | |

これらのパラメータは参照しません。
